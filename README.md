# NOIR — Glass Calculator 🖤

### Precision in Every Tap.

NOIR is a modern glassmorphism calculator featuring an elegant interface, smooth interactions, and a built-in calculation history for a seamless user experience.

### ✨ Features
- Modern Glassmorphism design
- Interactive calculator
- Live calculation display
- Basic arithmetic operations
- Percentage and sign controls
- Calculation history
- Clear All history option
- Responsive interface

### 🛠️ Technologies
- HTML5
- CSS3
- JavaScript
